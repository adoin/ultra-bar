# 宿主编辑器服务

编辑类型、原生控件、弹层、主题、字体、间距、焦点、键盘、IME、剪贴板及通用校验由 Ultra Bar 维护。插件提供字段声明、业务数据、选项、约束和业务校验结果，不提供编辑控件绘制代码。日历网格、统计图表、进度条、只读结果列表等展示仍允许插件自定义。

默认字体从系统已安装字体家族选择。共享绘制通过 `ultra_bar_native_ui::fonts::create_font` 创建字体，GDI 对象使用 `fonts::delete_object` 释放，以便跟踪默认文本、图标字形和代码等宽字体的不同用途。宿主将字体配置路径传给子进程，字体变更由已有窗口消息触发重绘和原生控件字体更新；不关闭草稿，不增加轮询。调用 `theme::handle_message` 的 SDK 窗口自动接入字体通知。

## 代码边界

原生控件与弹窗的圆角区域统一交给 `geometry::attach_rounded`；宽高取实际 HWND，不在业务布局中缓存或另设窗口区域。边框绘制读取 `geometry::corner_pixels`。重复挂载同一编辑会话只更新几何，不重建控件或覆盖草稿。审计与验证范围见 [control-geometry.md](control-geometry.md)。

- `crates/plugin-sdk/src/editors.rs`：数据协议；不依赖 Win32，也不包含绘制实现。
- `src/editors/`：主进程内的编辑器提供者、控件注册与渲染。
- `crates/native-ui/src/editor_bridge.rs`：原生插件的传输适配器；只传递声明和事件。
- `crates/native-ui/src/input.rs`：宿主输入底座，内置设置、搜索、表单、颜色编辑共用居中、背景合成和编辑快捷键。

官方插件不得创建 `EDIT`、`COMBOBOX`、日期时间等原生编辑控件，不得调用旧的插件本地 `form::edit`。需要新类型时扩展宿主注册表和协议，再发布宿主版本；不允许插件自绘编辑器作为兼容降级。未知类型或样式属性会拒绝，不会回退到系统白色输入框。

## 声明

协议版本为 1。字段使用稳定的 `id`，声明 `kind`、`label`、`value`、`options`、`constraints`；`span` 选择一列或两列。`visible_when`、`enabled_when` 提供引用其他字段值的条件，`any` 表示或，其余条件按且处理。控件颜色、字体、圆角和透明度不是插件参数。

类型目录包括文本、密码、搜索、多行、数值、单选、开关、多选、日期、时间、带时区日期时间、颜色、文件、目录、快捷键、标签、代码及 JSON。日期使用 `YYYY-MM-DD`，时间使用 `HH:mm`，带时区日期时间使用 RFC 3339；开关值为 `true/false`；单选返回选项的稳定 value，多选返回 JSON 字符串数组。数值、标签和编辑文本使用字符串承载，由宿主及业务方分别校验。

`Open` 创建宿主表单；`Mount` 将宿主编辑控件放入插件提供的展示区域。宿主 HWND 和实际输入 HWND 都由主进程创建，插件进程不绘制其客户区。`Settings` 跳转主程序设置中该插件的页面；`ChoosePath` 由宿主提供打开／保存文件选择。

## 事件和生命周期

宿主返回 `opened`、`change`、`submit`、`delete`、`closed` 事件；文件选择返回 `path`。使用原生 SDK 面板时调用 `Panel::editor(Operation)`，后端通过 `Command::Editor(EditorEvent)` 接收事件，调用 `Complete` 回传业务结果。自定义展示窗口可使用 `editor_bridge::request` 和同一 `EditorEvent` 协议。插件处理业务并发送 `Complete`：成功时允许关闭，失败时提供错误信息，宿主保留窗口、输入值、选择状态及撤销历史。普通字段联动和通用格式／范围校验由宿主处理，日程规则、农历换算和保存仍在日程插件中。

跨进程报文使用有上限的内存传输，不写表单值到文件；仅接受已加载插件的窗口和可执行文件身份。插件升级时，已打开表单仍允许原业务进程完成该会话。宿主通过独立事件线程通知插件，并合并高频 change，编辑绘制不等待插件业务代码；不新增持续绘制或网络轮询。

主程序退出／热重载会检查未关闭的编辑会话。开发运行器使用正常退出协议，编辑器或未保存设置存在时保留当前进程，不强制结束窗口。内嵌控件会先于对应插件进程停止而销毁。

## 内嵌设置的选择与字段操作

内嵌设置中的非布尔 `Choice` 复用宿主单选下拉控件；布尔选项仍使用 switch。展开不改变当前值，关闭的下拉框不会通过滚轮轮换选项，所有控件沿用宿主字体、主题及几何规则。

原生面板可用 `form::Field::with_action(id, tooltip, icon)` 为字段声明附加图标操作。宿主通过 `SaveRequest.action`、`request_id` 和当前草稿 `values` 发送请求，`action=None` 才表示保存。提供操作的面板必须分别处理这两条路径；测试等只读操作不写配置或凭据。完成后调用 `settings_bridge::publish_action_result`，仅更新结果和通知宿主，保留 schema revision、未保存草稿及密钥输入。图标、命中区域、忙碌状态和提示由宿主绘制，具体校验在插件后台处理。

## 验证入口

所有检查通过受 CPU 限制的 `dev.ps1`。`--editor-host-smoke <绝对目录> [schema.json]` 验证实际控件所属进程、单行文字区域居中、提交事件和校验后的草稿及撤销保留；`--plugin-services-smoke` 的测试宿主验证搜索输入框与插件分属不同进程。测试使用独立配置及离屏窗口，不发送全局键鼠输入。
